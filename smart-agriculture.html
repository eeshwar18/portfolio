Overview

Smart Agriculture is an IoT-based system focused on monitoring agricultural conditions and supporting automated irrigation.

The project combines sensors, microcontrollers and IoT connectivity to collect environmental information and make the system easier to monitor.

Platform Arduino + ESP32
Connectivity IoT / Wi-Fi
Monitoring Blynk
02

Problem

Agriculture systems can benefit from continuous monitoring of environmental conditions and more responsive irrigation.

03

Solution

The system uses sensors to collect environmental information. Arduino and ESP32 are used as the processing and connectivity components, while Blynk provides IoT-based monitoring.

The system can use the collected information to support irrigation decisions and monitoring.

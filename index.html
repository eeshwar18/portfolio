Things I've Built.

A selection of my embedded systems, IoT, electronics and robotics projects.

PROJECT 01

Smart Agriculture

An IoT-based smart agriculture system built using an ESP32 and Blynk. The system monitors temperature, humidity, soil moisture and light levels and uses a relay to control irrigation automatically when the soil becomes too dry.

ESP32 Blynk DHT22 Soil Sensor LDR IoT

PROJECT 02

Smart Arduino Car

A sensor-based robotic car built using an Arduino UNO. It uses ultrasonic and IR sensors to detect obstacles and a servo motor to scan different directions while the Arduino controls the movement system.

Arduino UNO Embedded C/C++ Ultrasonic IR Sensors Servo L298N
View Project →
PROJECT 03

Raspberry Pi Smart Car

A Raspberry Pi Zero 2 W based robotic car designed for obstacle detection. An ultrasonic sensor mounted on a servo scans different directions while the Raspberry Pi processes the readings and controls the motors through an L298N driver.
